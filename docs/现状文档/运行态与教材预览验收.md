## 4. 真实浏览器发现与修复

### Nginx 限制不一致

- 修复前：7.4MB的《第二章 并列句.pdf》小于后端10MiB，但经Nginx预览收到HTML 413。
- 根因：Nginx默认请求体上限约1MiB，比应用文件上限更低。
- 修复：`frontend/nginx.conf` 添加 `client_max_body_size 11m`，给10MiB文件的multipart metadata留空间；实际文件上限仍由后端10MiB控制，不是把课程87MB文件直接放行。
- 修复后：相同PDF、相同浏览器前端路径，预览200。

### 无文字预览不能伪装为可入库

- Preview响应增加 `indexable/reason_code/message`；无文字PDF仍返回页码和warning，但 indexable=false、chunks=0。
- 新 `KNOWLEDGE_NO_INDEXABLE_TEXT` typed error；服务在调用indexer/embedding前拒绝仅有page_break的扫描PDF。
- UI扫描件预览后禁用上传，明确提示OCR；空文字的覆盖率显示“不适用（没有文字）”，不再把数学上的空集合覆盖率1.0显示成“教材已完整处理”。
- 文件超10MiB时本地直接提示并禁用预览/上传；没有抬高后端文件限制掩盖缺口。
- 正式索引仍会调用用户配置的embedding；提示文案与“预览不调用模型”清楚区分。
